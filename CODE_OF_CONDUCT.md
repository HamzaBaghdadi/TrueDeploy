# Code of conduct

TrueDeploy follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks aren't welcome in issues, pull requests, discussions, or anywhere else the project lives.

To report a problem, contact the maintainer privately through [GitHub](https://github.com/HamzaBaghdadi). Reports are handled confidentially.
